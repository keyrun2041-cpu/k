=======================

Files:
- index.html
- style.css
- script.js
- assets/profile.jpg

UPLOAD:
Upload the whole folder to your hosting/public_html directory.
For kirankhakural.com.np, make sure index.html is in the domain's document root.

PHOTO:
The website intentionally uses one image: assets/profile.jpg.
To change the photo later, simply replace assets/profile.jpg with another JPG
and keep the same filename. The site will use the new photo automatically.
